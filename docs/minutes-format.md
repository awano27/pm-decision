# 議事録の渡し方（Copilot の要約から）

会議の後、Microsoft 365 Copilot に下のプロンプトで箇条書きを作らせ、メモ帳に貼って
`inbox` フォルダに `.txt` で保存する。次の daily サイクル（または `watch`）が 1 行ずつ判断する。

## 形式

```text
週次定例 2026-10-02
- 決定: v2.3 のリリースは 10/8 とする
- タスク: 負荷試験の結果を共有する / 担当: 田中 / 期限: 10/6
- タスク: ログ基盤の見直し案を作る / 担当: 未定 / 期限: 未定
- リスク: 決済 API の移行が 1 週間遅れる可能性
- 共有: 前回の振り返り結果を説明した
```

- 1 行目: 会議名と日付（日付がなければファイル名の日付、それもなければ保存日）
- `- ` で始まる行が 1 項目。先頭のラベルで種類が決まる（`【タスク】` のような括弧も可）

| ラベル | 行動 |
|---|---|
| `決定:` / `決定事項:` / `合意:` | 決定ログに投稿 |
| `タスク:` / `TODO:` / `宿題:` / `アクション:` | 担当と期限があれば Task 作成。`未定` や記載なしなら担当・期限の確認依頼 |
| `リスク:` / `懸念:` / `課題:` | 対策の進め方（プレイブック）を選んで Risk 登録 |
| `共有:` / `報告:` / `情報:` / `メモ:` | 記録のみ |

ラベルのある行はルールで決まり、モデルは使わない（速く、ぶれない）。ラベルのない行や、
担当・期限の書き方が違う行は、これまでどおり Kev / Jev が判断する。

## Copilot へのプロンプト（Teams の会議チャットや Copilot で）

```text
この会議の内容を、次の形式の箇条書きだけで出力してください。前置きや説明は不要です。
1 行目: 会議名 YYYY-MM-DD
2 行目以降: 1 項目 1 行、必ず「- 」で始め、先頭に次のラベルのどれかを付ける
  決定: 会議で決まったこと
  タスク: 誰かがやること。「/ 担当: 名前 / 期限: M/D」を付ける。分からなければ「未定」と書く
  リスク: まだ起きていない懸念や遅れの可能性
  共有: 報告や説明だけで、決定・タスク・リスクでないもの
1 行に 1 つの内容だけを書き、複数のタスクは行を分けてください。
```

保存時の文字コードは UTF-8（Windows 11 のメモ帳の既定）。古いメモ帳の Shift_JIS でも読める。
名前などの個人情報を含むので、議事録ファイルは PC の外に出さない（Kev はローカルで判断する）。
